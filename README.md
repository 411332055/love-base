# 我們的戀愛遊戲基地

兩個人專用的小網站：一起寫日記、傳照片、許願、抽題，資料即時同步。

網址：https://411332055.github.io/love-base/

## 怎麼使用

1. 打開網址，輸入你們約好的暗號，選「寒冰」或「夏夏」。
2. 手機可以加到主畫面，步驟在「更多」→「設定」裡。
3. 輸入同一組暗號就會進到同一個基地，看到同一份資料。

暗號是這個基地唯一的門鎖，知道的人就能看和修改全部內容，所以請用別人猜不到的長暗號，也不要外流。忘記暗號就進不去了，網站沒有找回功能，請自己記在安全的地方。

## 選單

手機在底部、電腦在左側，一次只顯示一個區塊。

| 分類 | 內容 |
|---|---|
| 今天 | 稱號和 XP（含百日／里程碑倒數）、提醒、討抱抱（與一週前的今天快捷鈕）、今天還差什麼、連續天數 |
| 日記 | 今天的照片和日記（可按表情貼圖與留言回應）；星期日多一個「這週回顧」 |
| 互動 | 抽題（每天輪流抽一題、每月換主題，揭曉前可修改答案、可自訂題目）、願望清單（可分類：想吃、想去、想做，已完成自動收合） |
| 回憶 | 月曆（含全部日記）、照片牆（大圖支援下滑關閉）、回顧（含回憶扭蛋機、那年／那月／上週的今天）、時光膠囊、回憶書（每月總結與年度總結） |
| 更多 | 成就稱號、規則、設定（手機推播通知、垃圾桶、備份、照片空間、更換基地暗號、外觀、震動回饋與強度、區塊順序） |

## 計分

XP 是兩個人共用的一個總分，所有加分都要兩個人一起達成，而且沒有扣分：完成過之後，就算刪掉日記或照片，分數也不會減少。

| 同一天兩個人都完成 | XP |
|---|---|
| 傳照片 | +10 |
| 星期日寫這週回顧 | +10 |
| 連續每滿 7 天（兩人當天都有傳照片或寫日記） | +10 |
| 抽題過關（兩個人都回答完同一題） | +10 |

2026-11-16（含）以前兩個人都寫日記的 +10 XP 會永久保留；從 2026-11-17 起日記改為自由填寫、不加分。許願和完成願望也不加分。

## 震動沒有感覺

到「更多」→「設定」按「📳 測試震動」，看按鈕旁邊的字：
- 寫「已經叫手機震了」卻沒震：手機在**靜音模式**，或系統的觸控震動被關掉。Samsung 要切到「震動」或「音效」模式。
- 寫「這個瀏覽器不支援震動」：可能是在 LINE、IG 裡打開的，請改用 Chrome。
- iPhone 需要 iOS 18 以上，而且強度固定。

## 資料備份

到「更多」→「設定」→「資料備份」下載。備份檔是一個 HTML，用瀏覽器打開就能讀，也能用同一個檔案把資料補回網站。補回時只會新增目前沒有的資料，不會改動現有內容。

## 檔案

| 檔案 | 用途 |
|---|---|
| `index.html` | 網站的畫面結構 |
| `style.css` | 外觀樣式（顏色、排版） |
| `app.js` | 所有功能的程式 |
| `sw.js` | 讓網站沒網路也打得開 |
| `manifest.webmanifest`、`icon-*.png`、`apple-touch-icon.png` | 加到手機主畫面用的設定和圖示 |
| `firestore.rules` | Firebase 資料庫的安全規則 |
| `questions.json` | 每個月的抽題題庫（主題和題目） |
| `GEMINI.md` | 給 Gemini 等 AI 助手的修改須知，請它改網站前先讀 |
| `HANDOFF.md` | 專案交接文件：資料結構、程式位置、做過的決定、還沒做的事 |

## 維護

- **網站**：放在 GitHub Pages，由 `main` 分支的根目錄發布，推送到 `main` 後約一兩分鐘更新。
- **資料**：存在 Firebase Firestore（專案 `love-base-eec24`），路徑是 `rooms/{暗號}/{集合}/{文件}`。
- **集合**：`diary` 是日記，`photos` 是縮圖和說明，`pics` 是原圖。願望、抽題、膠囊、回應、加分紀錄等其他資料都放在 `done`，文件 id 的格式是 `x~種類~id`，這樣就不用另外改規則。
- **規則**：修改 `firestore.rules` 後，要到 Firebase 主控台的 Firestore「規則」頁貼上並發布才會生效。
- `index.html` 裡的 Firebase apiKey 公開是正常的，真正保護資料的是規則和暗號。

## 抽題題庫

- 寒冰和夏夏**隔天輪流**抽題，一天一題；輪到的人在還沒有人作答前可以「換一題」。
- 題目來自 `questions.json`，每個月一組，格式是 `"年-月": { "theme": "主題", "q": ["題目", ...] }`。目前寫到 2027 年 10 月。
- 某個月沒有題庫時，會改用 `app.js` 裡的基本題庫 `QUESTIONS`。自訂題庫的題目每個月都會一起抽。
- 要新增月份，只要在 `questions.json` 加一組就好，不用改程式。
